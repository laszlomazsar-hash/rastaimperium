# Article VI — Alignment

Alignment requires the system to remain coherent with declared values over time, not only at launch.
Governance must detect and correct drift before it compounds.

## Constitutional intent

This article ties optimization activity to normative commitments.
It prevents short-term performance gains from eroding foundational intent.

## Operational controls

- Value maps define acceptable tradeoffs and red lines.
- Drift detectors monitor model behavior against constitutional baselines.
- Alignment exceptions trigger remediation workflows with bounded timelines.
- Benchmark suites include adversarial and long-horizon evaluations.

## Stewardship note

Alignment is stewardship in motion.
A constitution is alive only when values are continuously enforced in practice.

## Repository role

- Public-facing architecture and governance documentation
- Institutional communication and verification surface
- Conceptual and constitutional framing for EVO-V
- Sealed public capsules and independent verifiers (where published)

## Explicit non-goals

This repository must not contain runtime execution logic for EVO-V governance operations.
Production performance, live telemetry, and full kernel parity are **not** claimed without sealed public artifacts. See [Limitations](https://rastaimperium.com/limitations).

## Core message

1. EVO-V is a deterministic governance kernel (separate execution layer).
2. Rastaimperium is the constitutional / verification surface.
3. Execution occurs in separate EVO-V repositories and operational systems.
4. Claims on this surface are evidence-bound: VERIFIED, DEMONSTRATION, or UNAVAILABLE.

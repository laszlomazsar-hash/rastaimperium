Architecture

Split by design. United by evidence.

The architecture is intentionally split between a public narrative layer (this site) and a separate execution layer (EVO-V runtime). This separation protects clarity, governance accountability, and implementation discipline.

Public narrative layer

This website. Architecture diagrams, codex, governance framing, and institutional communication. No runtime execution.

Execution layer (EVO-V)

Separate repositories and operational systems. Deterministic governance logic, replay, and evidence production live here.

Evidence boundary

Replay proofs, hash-linked lineage, and .evop containers bridge the two layers without collapsing them.

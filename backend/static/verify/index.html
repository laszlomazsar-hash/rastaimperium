Verification flow

Authoritative verification runs offline in a pure verifier. The browser is not the decision authority.

  1. 01

    Input

    Obtain the sealed ART-L7 capsule JSON from this site or the repository.

  2. 02

    Verify

    Run the matching pure verifier (Node or Python). No network.

  3. 03

    Checks

    Hash, structure, and capsule-specific invariants as declared in the verifier.

  4. 04

    Reproduce

    Exit 0 and exact sealed-hash match are the independent result.

How to read a pure-verifier result

Labels below describe offline verifier outcomes. They are not website-issued certificates. Public L7 capsules on this surface are already recorded as VERIFIED in the Living Evidence Manifest after independent hash agreement.

  • VERIFIED

    Hash agreement (exit 0)

    Independent pure verifier recomputed values match the sealed targets in the capsule.

  • INVALID

    Mismatch (non-zero exit)

    Declared sealed hashes do not match recomputed digests, or required fields fail checks.

  • SPEC_DRIFT

    Spec / fixture drift

    Artifact shape or expected fields do not match the verifier’s declared contract for that capsule.

  • MALFORMED

    Malformed input

    JSON cannot be parsed or required structure is absent. Distinct from a cryptographic mismatch.

  • INDETERMINATE

    Indeterminate

    Available information is insufficient for a definitive pure-verifier result (rare for frozen public capsules).

Preserve independently

Rasta Imperium does not control the evaluator’s archive. Preserve what you inspected.

  1. Download or copy the sealed artifact JSON exactly as published.
  2. Preserve the pure-verifier script(s) or repository revision you used.
  3. Preserve REPRODUCE_OFFLINE.md / PURE_VERIFIER_README.md as inspected.
  4. Record environment (runtime version) and exact command.
  5. Record exit code and any locally computed digests — label them as local reproduction results.
  6. Do not treat this website session as the authoritative archive.

    Obtain capsule

    Download the sealed ART-L7 JSON artifact (or clone the repository).

  2. 02

    Run verifier

    Node.js or Python pure verifier. No network required. No mutation of the artifact.

  3. 03

    Compare deterministic result

    Exit code 0 and exact hash match against sealed expected values.

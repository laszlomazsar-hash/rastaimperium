Kernel responsibilities

What the execution layer is for

Lifecycle guards

Guard state changes through explicit transition semantics. Illegal edges reject with sealed receipts where capsules exist.

Audit lineage

Preserve hash-linked chronology across committed operations so reviewers can reconstruct what entered and what changed.

Deterministic replay

Support identical terminal state, receipt, and ledger head under identical inputs, versions, and event order — capsule-scoped where VERIFIED.

Boundary

Public VERIFIED labels apply only to sealed capsules and pure verifiers published on this site. Full production fleets, LIVE telemetry, and unpublished kernel paths remain outside those labels until sealed artifacts exist. See Limitations.

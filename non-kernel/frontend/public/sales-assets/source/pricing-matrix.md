# Pricing Matrix (Draft)

> All values are configurable and should be validated during each quarterly pricing review.

| Tier | Ideal customer profile | Includes | Indicative price | Expansion path |
|---|---|---|---:|---|
| Foundation | Teams launching first governed AI workflow | Workspace setup, governance baseline, core telemetry dashboard | £12,500 setup + £2,500/mo | Add advisory days and additional integrations |
| Growth | Multi-team programs needing stronger controls | Foundation + advanced governance policies, deployment runbooks, monthly review | £25,000 setup + £6,000/mo | Add business unit workspaces and premium support |
| Enterprise | Regulated/complex organizations with broad rollout goals | Growth + enterprise governance engine, custom telemetry views, executive reporting | £60,000+ setup + £15,000+/mo | Seat expansion, dedicated pod, regional deployment extensions |

## Revenue tier notes

- Seat-tier pricing applies for enterprise workspace scale.
- Advisory retainers can be bundled with governance maturity targets.
- Optional deployment assurance package can be attached for high-risk release environments.

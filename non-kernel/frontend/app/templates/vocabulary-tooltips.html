Implementation Guide

Step 1: Add the CSS

Copy this CSS into your stylesheet or add to your site's <head> section:

/* Tooltip Base Styles */ .term { position: relative; color: #D4AF37; border-bottom: 2px dotted #D4AF37; cursor: help; transition: all 0.2s ease; } .term:hover { color: #C49F2F; border-bottom-color: #C49F2F; } .tooltip { position: absolute; bottom: 100%; left: 50%; transform: translateX(-50%) translateY(-8px); background: white; border: 1px solid rgba(212, 175, 55, 0.3); border-radius: 8px; padding: 1rem 1.25rem; box-shadow: 0 8px 24px rgba(0,0,0,0.15); width: 320px; z-index: 1000; opacity: 0; pointer-events: none; transition: all 0.3s ease; } .term:hover .tooltip { opacity: 1; transform: translateX(-50%) translateY(-12px); } /* Tooltip arrow */ .tooltip::after { content: ’’; position: absolute; top: 100%; left: 50%; transform: translateX(-50%); border: 8px solid transparent; border-top-color: white; }

Step 3: Customize Colors (Optional)

Step 4: Mobile Optimization (Optional)

For mobile devices, consider adding click-to-show behavior with JavaScript:

// Make tooltips work on mobile with tap document.querySelectorAll(’.term’).forEach(term => { term.addEventListener(‘click’, (e) => { e.preventDefault(); term.classList.toggle(‘active’); }); }); /* Add to CSS */ .term.active .tooltip { opacity: 1; transform: translateX(-50%) translateY(-12px); }

Complete Vocabulary Glossary

Use these definitions as the basis for your tooltip content. Each term includes a concise explanation designed for first-time visitors.

Term Definition (For Tooltips)
Mythic-Technical Field A space where symbolic/archetypal frameworks (mythic) integrate with practical systems and code (technical) to create aligned structures.
Covenant Field A shared space governed by mutual agreements and commitments—like a treaty zone where all participants align to core principles.
Covenant Architecture Governance frameworks built on mutual agreements and shared principles, creating stable foundations for collaboration.
Treaty-Grade Alignment Rigorous, binding agreements on values and protocols—equivalent to international treaty standards—ensuring all parties remain coherent to shared purpose.
Recursive Architecture Self-referencing systems that can examine and improve themselves while maintaining alignment to original purpose. Think: AI systems that evolve without drift.
EVO-V Civilization Kernel The foundational operating system layer—a simulation engine for modeling evolutionary intelligence and civilizational dynamics.
ARK Engine A technical framework for building worlds, systems, and intelligences that remain aligned to their founding covenant as they grow.
Sovereign Architecture Self-governing systems that maintain independence and agency—not controlled by external forces, but aligned to internal purpose.
Codex A collection of foundational texts, principles, and tools—like a constitution combined with an instruction manual. In practice: books, card decks, and calibration instruments.
Daily Resonance A simple daily practice using 12 archetypal cards to tune into clarity and coherence. No doctrine or force—just a reflective tool to read your own signal.
Lineage The traceable origin and continuity of ideas, practices, or systems—ensuring they remain connected to their source and purpose over time.
Calibration The process of tuning your internal state (thoughts, emotions, intentions) to align with your values and goals—like tuning an instrument before playing.
Symbolic Systems Frameworks that use symbols, archetypes, and patterns to represent complex ideas—making abstract concepts tangible and workable.
Field A living space or environment (digital or conceptual) where principles, practices, and communities interact—not a static website, but an evolving ecosystem.
Pro Tip: Strategic Placement
Don't tooltip every term—only the ones that are truly unfamiliar or essential. Over-tooltipping creates visual noise. Focus on terms that appear early in the user journey (homepage, first gateway) and that are fundamental to understanding your system.

# GLOSSARY

## Event
An append-only record representing a discrete system action or observation in ordered lineage.

## State
A formally defined lifecycle condition of an entity within a constrained transition model.

## Kernel
The execution core that applies governance rules, enforces invariants, and produces deterministic outcomes.

## Replay
Deterministic reconstruction of state from ordered events under a fixed version bundle.

## Audit
Verifiable record of actions, transitions, and outcomes suitable for institutional assurance.

## Lineage
Hash-linked historical sequence that preserves provenance and ordering integrity.

## Counterexample
Canonical failure artifact produced when a critical invariant is violated.

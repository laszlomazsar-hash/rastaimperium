# Deck Section Blueprint Alignment

Use this sequence for sales deck generation and reviews.

1. **Cover + thesis**
   - Theme: governed AI execution for enterprise scale.
2. **Enterprise workspace**
   - Show role-based collaboration and operating model.
3. **Governance engine**
   - Explain policy, traceability, and oversight architecture.
4. **Telemetry system**
   - Present operational + governance signal layers and KPIs.
5. **Deployment model**
   - Summarize layered stack, release flow, and rollback safety.
6. **Revenue tiers**
   - Present foundation, growth, and enterprise pricing paths.
7. **Adoption journey + CTA**
   - Discovery sprint, implementation roadmap, and collateral request.

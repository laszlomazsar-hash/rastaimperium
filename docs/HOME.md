# EVO-V Documentation Home

Rastaimperium is the **public constitutional and conceptual layer** for EVO-V.

This website and documentation set are designed for institutions, researchers, and developers who need a clear understanding of how EVO-V is governed and why determinism is foundational.

## What this site is
- A documentation and narrative interface for EVO-V.
- A constitutional reference for governance principles and invariants.
- A communication layer for architecture, pilots, and public accountability.

## What this site is not
- Not a runtime execution environment.
- Not an event processor.
- Not an agent implementation surface.
- Not a simulation engine.
- Not backend governance execution logic.

## Separation of layers
- **Rastaimperium (this repository):** constitutional, explanatory, and institutional presentation layer.
- **EVO-V execution layer (separate repository):** runtime kernel, event handling, enforcement, and operational execution.
